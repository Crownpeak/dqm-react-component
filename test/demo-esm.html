📦 ES Module Import Integration

So funktioniert's

Das Widget wird als ES Module importiert und manuell initialisiert.

<script type="module">
  import { initDQMWidget } from '/dist/dqm-widget.esm.js';
  
  initDQMWidget({
    apiKey: 'your-api-key',
    websiteId: 'your-website-id',
    initialOpen: false,
  });
</script>

Manuelle Steuerung

Mit window.DQM_MANUAL_INIT = true kann die Auto-Initialisierung verhindert werden:

<script>
  window.DQM_MANUAL_INIT = true;
</script>
<script type="module">
  import { initDQMWidget } from '/dist/dqm-widget.esm.js';
  
  // Später manuell initialisieren
  document.getElementById('btn').onclick = () => {
    initDQMWidget({ initialOpen: true });
  };
</script>
