📜 IIFE Script-Tag Integration

So funktioniert's

Das Widget wird über ein einfaches <script>-Tag geladen und initialisiert sich automatisch.

<!-- 1. Konfiguration setzen (optional) -->
<script>
  window.DQM_CONFIG = {
    apiKey: 'your-api-key',
    websiteId: 'your-website-id',
  };
</script>

<!-- 2. Widget laden -->
<script src="/dist/dqm-widget.iife.js"></script>

Status

✅ Das Widget sollte als Floating Action Button (FAB) unten rechts erscheinen.

Klicke darauf, um die DQM Sidebar zu öffnen.
