📜 IIFE Script-Tag Integration

How it works

The widget loads via a simple <script> tag and auto-initializes.

<!-- 1. Set configuration (optional) -->
<script>
  window.DQM_CONFIG = {
    apiKey: 'your-api-key',
    websiteId: 'your-website-id',
  };
</script>

<!-- 2. Load widget -->
<script src="/dist/dqm-widget.iife.js"></script>
